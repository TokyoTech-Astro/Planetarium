# プラネ統合制御システム 20261010-6

ステップ移動時の5°/s位置合わせ、最初から再生時の反時計回り0°復帰画面、速度の正負による方向指定、フェード時間の3秒/5秒プリセットを追加。詳細は `変更点_20261010-6.txt` を参照してください。操作者用EXEは `PlaneControl_v20261010-6.exe` です。方向指定とフェード処理の変更を使うには、統括基板とライト基板へこの版を書き込んでください。

## ライトのフェード中に見える点滅を改善

ライト基板の10系統を、通信処理やログ出力によって間隔が変わるメインループから切り離し、20 kHzの固定タイマーで明るさ制御するように変更しました。暗部で間隔の長い単発パルスが見えないよう、1〜3/255の微小な明るさは消灯として扱います。t^4／(1-t)^4 とフェード時間、ESP-NOWの通信形式は変更していません。

この変更を使うには、`firmware/light_controller` をライト基板へ書き込む必要があります。統括基板とUIアプリは更新不要です。2026年10月10日にライト基板と統括基板の両方のコンパイル成功を確認し、`ビルド成果物` に保存しました。基板への書き込みはまだ実施していません。`送信用` と `送信用.zip` は新しいライト基板コードに更新しています。

## 今回のUI追加

`操作者用/PlaneControl_v20261010-4.exe` に、上映中でも使えるモーター手動操作を追加しました。指定角度と速度を入力して時計回り／反時計回りへ相対移動できます。手動モード中も音声とライトのタイムライン制御は続きます。基板との通信形式は変更していません。

モーター手動モードの開始時にライトの手動上書きを解除し、自動変更をONにします。音声一時停止時には手動移動も停止します。通信断後の手動移動は自動再開しません。操作の詳細は `UIアプリの使用手順.txt` を参照してください。

音声一時停止・再生終了時はモーター速度0を即時送信し、定期送信や通信再接続でも停止を維持します。再生再開時は現在の指令値を再送します。停止中に手動モーター操作を行う場合は、速度の上書きをONにし、手動速度を入力してEnterを押してください。校正中・緊急停止中の音声再生は拒否します。UI終了時も停止指令を送信します。

## 星座割り当てとCOMポート識別

設定画面から8系統の星座名を変更できます。この版は既存基板の固定配線を使用し、出力ピンの変更指令を送信しません。系統5/D5はこぐま座です。TXTの列順は従来の系統1〜8のままです。

COM一覧は機器名を併記します。更新時にUSBシリアル機器へidentifyを送り、統括基板のhelloまたは既存status応答で識別します。手動選択も可能です。接続成功した機器の識別情報を保存します。

既存のESP-NOWプロトコルv3の基板で使用できます。基板への書き込みは不要です。操作者用の2024番組_指示送信設定.txtに、こぐま座104秒ON・149秒OFFを復元しました。同梱ファイルは旧フォルダの同名ファイルより優先して読み込みます。EXEはPlaneControl_v20261009.exeです。

## 20260725 通信安定化

- PCと統括・モーター基板のUARTが切れた場合、UIは接続したUSB機器を1秒間隔で探して自動再接続します。
- 再接続後は通信設定と現在の全設定値を自動送信します。
- 統括・モーター基板からPCへのJSON送信を排他制御し、状態通知とイベント通知が途中で混ざらないようにしました。
- ライト基板はESP-NOW通信が切れても、最後に受信した恒星・一等星・星座の状態を保持します。通信断は状態LEDの高速点滅だけで通知します。
- 手動ON/OFF時は明るさ0/255をPWM処理から外し、星座ライトが周期的に瞬間消灯しないようにしました。

統括・モーター制御とライト制御の両方にXIAO ESP32C3を使用します。

- `firmware/coordinator`: PCとのUART、モーター直接制御、ライト基板とのESP-NOW通信
- `firmware/light_controller`: 一等星、恒星、星座出力と状態返信

## 20260717 星座配線

ライト基板の物理出力は既存ファームウェアのビット配列を使用し、UI側で次の名称へ割り当てます。

- D2: オリオン座
- D3: おおいぬ座
- D4: こいぬ座
- D10: さそり座
- D9: いて座
- D8: ペガスス座
- D7、D5: 未接続（UI側で常時OFF）
- `pc_ui`: Windows操作UIとEXE
- `docs`: 配線、設定、通信仕様

従来の独立したモーター制御マイコンは廃止し、統括マイコンへ統合しました。統括・モーター基板とライト基板の2台構成です。

ESP32C3はシングルコアのため、USB CDC・ESP-NOW・JSON処理はFreeRTOS通信タスクで動作します。モーターのCLOCK生成はハードウェアタイマー割り込みへ分離しているため、通信処理中もステップパルス生成を継続します。

## ビルド

各有効プロジェクトのフォルダーで次を実行します。

```powershell
pio run
```

書き込み前に、`firmware/coordinator/platformio.ini` のモーター1回転ステップ数、マイクロステップ数、回転方向を実機に合わせてください。
