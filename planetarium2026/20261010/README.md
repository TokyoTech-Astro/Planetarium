# プラネ統合制御システム 20261010

## 変更内容

- フェードインt^4、フェードアウト(1-t)^4。tは0〜1の正規化経過時間。
- 旧上映資料に合わせて初期時間5秒。UI設定から0〜600秒で変更・保存可能。0秒は即時。
- 音声再生中の自然なSTEP変更だけフェード。手動操作・シーク・緊急停止は即時。
- ESP-NOW Version 5でフェード時間を送信。

**統括・ライト両基板に本版の書き込みが必要です。旧Version 3/4と混在できません。** ファームウェアのコンパイル・書き込み・実機試験は未実施。UIのEXEは作成済みで、非接続の停止・再開テストとフェード設定送信テストを実施しました。

## 構成

- `操作者用`：Windows用EXE、統合WAV、上映TXT、説明書。
- `firmware/coordinator`：XIAO ESP32C3、UART・モーター制御・ESP-NOW。
- `firmware/light_controller`：XIAO ESP32C3、ライト出力。
- `firmware/common`：共通通信形式。
- `pc_ui`：UIソース・ビルドスクリプト・requirements・非接続テスト。
- `docs/PROTOCOL.md`：現行通信仕様。
- `フェード変更点.txt`：旧資料との対応・更新注意事項。

## 運用

操作者用のPlaneControl_v20261010.exeを起動し、同梱TXTとWAVを指定します。詳細は操作者用/説明書/UIアプリの使用手順.txtを参照してください。

同梱の仕様書PDFは20261009-2時点の参考資料です。フェードと通信版については本版の変更点・PROTOCOL.mdを優先してください。

固定配線：D7予備、D8ペガスス、D9いて、D10さそり、D5こぐま、D4こいぬ、D3おおいぬ、D2オリオン。UIで変更できるのは表示名です。

## 開発

firmwareの各プロジェクトをPlatformIOで開きます。UIはPython 3.9とrequirements.txtの依存パッケージを使用します。build_exe.ps1のPython・依存フォルダのパスは開発PCに合わせて変更してください。vendor、ビルドキャッシュ、重複EXEは含めていません。

WAVはGit LFS管理です。運用時はソフトウェア停止だけに依存せず、電源遮断手段も確保してください。
