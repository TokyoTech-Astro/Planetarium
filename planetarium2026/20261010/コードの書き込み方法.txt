マイコンへコードを書き込む方法（保守担当者向け）
================================================

※通常のプラネタリウム操作者は、この作業を行う必要はありません。
※誤った基板へ書き込むと動作しなくなるため、基板を1台ずつPCへ接続してください。

1. 必要なソフト
----------------
・Visual Studio Code
・Visual Studio Code用 PlatformIO IDE 拡張機能
・データ通信対応のUSB Type-Cケーブル

2. 書き込むプロジェクト
----------------------
統括・モーター基板：
  firmware\coordinator

ライト制御基板：
  firmware\light_controller

どちらも Seeed Studio XIAO ESP32C3 用です。

3. 書き込み前の安全確認
----------------------
1) UIアプリを終了します。
2) モーターとライトが動いても危険がない状態にします。
3) 原則として24V電源を切ります。
4) 書き込む基板だけをUSB Type-CでPCへ接続します。
5) ほかのXIAO基板はPCから外しておきます。

4. Visual Studio Codeから書き込む方法
-------------------------------------
1) Visual Studio Codeを起動します。
2)「ファイル」→「フォルダーを開く」を選びます。
3) 書き込む側のプロジェクトフォルダを開きます。
4) PlatformIOのチェックマーク（Build）でコンパイルします。
5) エラーがないことを確認します。
6) PlatformIOの右矢印（Upload）を押します。
7) SUCCESSと表示されるまでUSBケーブルを抜かないでください。

5. PlatformIOターミナルから行う場合
-----------------------------------
各プロジェクトフォルダで次を実行します。

  コンパイル： pio run
  書き込み：   pio run --target upload

COMポートを指定する場合の例：

  pio run --target upload --upload-port COM6

COM6の部分は、そのPCで表示されたポート番号へ置き換えてください。

6. 書き込み後
-------------
1) SUCCESSを確認します。
2) USBを一度抜き、通常の配線へ戻します。
3)「UIアプリの使用手順.txt」の順番で電源を入れます。
4) UIでPC、統括・モーター基板、ライト基板の通信が正常か確認します。
5) モーター基板を書き換えた後は、必ずモーターの0°位置設定を行います。

注意事項
--------
・firmware\common\protocol.h を変更した場合は、統括基板とライト基板の両方を
  同じ版へ更新してください。
・書き込み中はUSBを抜いたり、PCを終了したりしないでください。
・モーターが予期せず動いた場合は、24V電源を切ってください。
