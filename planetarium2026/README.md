# プラネタリウム統合制御システム（2026）

最新版は [20261010](20261010/) です。旧上映と同じ4乗曲線のフェード、初期時間5秒、UIからの時間設定に対応します。

運用者は [操作者用](20261010/操作者用/) のEXE・WAV・上映TXTを使用してください。導入前に [版の説明](20261010/README.md) を確認してください。

**最新版には統括・ライト両基板のファームウェア更新が必要です。旧基板の通信Version 3/4とは混在できません。** 今回はファームウェアのコンパイル・書き込み・実機試験をしていません。

[20260714](20260714/) は保存用の過去版です。

WAVはGit LFS管理です。Git LFSを有効にしてcloneしてください。ZIPダウンロードでは実音声ではなく参照ファイルとなる場合があります。

```console
git lfs install
git clone https://github.com/TokyoTech-Astro/Planetarium.git
cd Planetarium
git lfs pull
```
